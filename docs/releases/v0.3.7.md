# v0.3.7 release notes

- **Correct public Google Group slug.** The group's real slug is
  `boardgamenightwg`; `bgn-wg` was wrong and never publicly resolvable. The
  join link, `+subscribe` address, members deep link, list mailto, share text,
  and both rendered group-name labels now use it, so installed devices stop
  pointing members and coordinators at an access-error page. Server-owned
  persisted identity — the receiver's `GROUP` wire key and the dedupe targets
  built from it — is deliberately unchanged
  (`docs/adr/0010-private-meeple-handoff.md#public-group-slug-correction--2026-09-29`).

## Release metadata and gates

- App version: `0.3.7`; Tauri derives Android `versionCode` **3007**.
- Updater contract: tag `v0.3.7`, asset `bgn-coordinator_0.3.7_arm64.apk`.
- Latest published version checked before this bump: `v0.3.5`. `0.3.6` is
  skipped: two open PRs already claim it, and the release workflow's
  tag-exists check would turn whichever merged second into a green no-op
  that publishes no APK.
- **Do not merge/release without owner approval**: merging triggers the
  signed arm64 publication workflow.
- Verification is the node:test suite (exported constants, rendered DOM and
  mailto output) plus the receiver's emitted-prompt and job-JSON assertions;
  the group itself was checked signed-out only, no mail or member action.
